Classic Auto — website-v5 — Studio 3D model, HDRI &amp; texture sourcing notes
================================================================================

Hero dust-sheet fabric (hero3d.js Verlet cloth reveal)
-------------------------------------------------------
Real woven-linen PBR set from Poly Haven, licensed CC0 (public domain —
no attribution legally required; credited here anyway):

  rough_linen (1k .jpg, dl.polyhaven.org):
    https://dl.polyhaven.org/file/ph-assets/Textures/jpg/1k/rough_linen/rough_linen_diff_1k.jpg
    https://dl.polyhaven.org/file/ph-assets/Textures/jpg/1k/rough_linen/rough_linen_nor_gl_1k.jpg
    https://dl.polyhaven.org/file/ph-assets/Textures/jpg/1k/rough_linen/rough_linen_rough_1k.jpg
    Saved to models/textures/fabric/rough_linen_{diff,nor_gl,rough}_1k.jpg.
    Licence: CC0. The diffuse map ships with a light-blue dye tint on Poly
    Haven — desaturated to neutral grey locally (Pillow: grayscale +
    autocontrast) before saving, so it multiplies cleanly with the
    material's own warm off-white tint (#f1ecdf) instead of fighting it.
    (First choice was fabric_pattern_07, but its diffuse turned out to be a
    bold red/cream gingham check — wrong read for a dust sheet — so this
    build swapped to rough_linen, a plain woven texture, instead.)
    Used as map/normalMap/roughnessMap on a MeshPhysicalMaterial with
    sheen, tiled ~2.2x per metre across the sheet's UVs so the weave reads
    at a believable physical scale.

website-v5 additions: real image-based lighting + a real road floor
---------------------------------------------------------------------
The Studio (studio.html) and the homepage cinematic hero (hero3d.js) now
light the scene from a real captured sky instead of hand-placed lights
alone, and the Studio floor is a photographed asphalt surface instead of
a flat grey material. All of the following are Poly Haven assets,
licensed CC0 (public domain — no attribution legally required; credited
here anyway, and via the "3D & studio credits" footer link on every page).

  HDRIs (1k .hdr, dl.polyhaven.org), loaded with RGBELoader + PMREMGenerator:
    Daylight — kloofendal_48d_partly_cloudy_puresky
      https://dl.polyhaven.org/file/ph-assets/HDRIs/hdr/1k/kloofendal_48d_partly_cloudy_puresky_1k.hdr
      Saved to assets/hdri/daylight.hdr — 1,435,119 bytes (~1.37 MB)
    Evening — moonless_golf
      https://dl.polyhaven.org/file/ph-assets/HDRIs/hdr/1k/moonless_golf_1k.hdr
      Saved to assets/hdri/evening.hdr — 1,672,754 bytes (~1.60 MB)
    Both under the site's 2 MB-per-HDRI budget. Licence: CC0.

  Road texture set (1k .jpg, dl.polyhaven.org) — asphalt_02, PBR triplet:
    https://dl.polyhaven.org/file/ph-assets/Textures/jpg/1k/asphalt_02/asphalt_02_diff_1k.jpg
    https://dl.polyhaven.org/file/ph-assets/Textures/jpg/1k/asphalt_02/asphalt_02_nor_gl_1k.jpg
    https://dl.polyhaven.org/file/ph-assets/Textures/jpg/1k/asphalt_02/asphalt_02_rough_1k.jpg
    Saved to assets/textures/asphalt/asphalt_{diff,nor,rough}.jpg. Licence: CC0.
    Painted lane lines on top of this texture are a small procedural
    canvas texture generated at runtime in studio.js (no separate asset).

  Car paint: the "body" mesh's material is upgraded at runtime from a
  flat MeshStandardMaterial to a THREE.MeshPhysicalMaterial (clearcoat 1,
  clearcoatRoughness 0.03, metalness 0.55, roughness 0.35) so swatches
  read as real automotive paint under the HDRI, tone-mapped with
  THREE.ACESFilmicToneMapping and sRGB output.

  Interior camera preset: verified against this model's own glTF node
  names (see below) — it DOES ship cabin geometry ("leather",
  "steering_leather", "steering_wheel", "carpet", "interior_dark",
  "interior_light"), so the Studio's "Interior" preset places the camera
  at approximate driver head height looking forward through the
  windscreen, rather than falling back to a photo strip.

Original website-v4 sourcing notes (model itself is unchanged in v5)
============================================================

Requested source order (per build spec): Kenney "Car Kit" -> Quaternius
Cars pack -> poly.pizza CC0 models -> generated CC0 primitive fallback.

What was actually used: car.glb (Ferrari 458 Italia)
------------------------------------------------------
Kenney's asset page (https://kenney.nl/assets/car-kit) and Quaternius
(https://quaternius.com) both render their download buttons via
client-side JavaScript with no stable direct-download URL reachable from
a script environment, and poly.pizza's model pages are likewise
JS-rendered — none were scriptable from this network. An earlier pass of
this build shipped a CC0 Khronos glTF-Sample-Assets "ToyCar" as a
stand-in, but that model renders as a stylized 1950s toy car (posed on a
velvet-draped pedestal) and reads wrong under real listing titles like
"2021 Hyundai Creta" — it has been removed and replaced with a proper car
body:

  Source:   three.js's own bundled example asset
            (three.js repo, tag r170: examples/models/gltf/ferrari.glb)
  Fetched:  https://raw.githubusercontent.com/mrdoob/three.js/r170/examples/models/gltf/ferrari.glb
  Used in:  three.js example "webgl_materials_car"
            (examples/webgl_materials_car.html)
  Model:    Ferrari 458 Italia, by vicent091036 on Sketchfab
            https://sketchfab.com/models/57bf6cc56931426e87494f554df1dab6
  Licence:  CC BY 4.0 (Creative Commons Attribution 4.0 International)
            — attribution required; credited here, in this file, and via
            a "3D model credits" link in the site footer on every page.

File size: 1,681,572 bytes (~1.6 MB), single glTF-Binary (.glb).

This single model is reused for every car in the Studio, across all body
types (hatchback / sedan / suv / luxury-sedan) — the Studio does not show
a different silhouette per body type. Per-car distinction comes from the
paint swatch (driven by each car's `paint` hex in assets/js/cars.js),
applied to the mesh named "body" (material "Body_Color") only — glass,
wheels/rims ("rim_fl"/"rim_fr"/"rim_rl"/"rim_rr") and interior "trim" are
left untouched, mirroring how three.js's own webgl_materials_car example
recolors this same model.

This is disclosed to the buyer on every Studio page: the badge reads
"STUDIO PREVIEW — ILLUSTRATIVE MODEL" and the caption under the viewer
reads "This is a preview model, not the car for sale — the photos and the
360° spin (when available) show the exact car." — consistent with the
hard rule that 3D models are always labelled illustrative.

If real Kenney/Quaternius/poly.pizza assets become reachable later (e.g.
downloaded manually and dropped in this folder), studio.js's MODEL_URL
constant and the body/glass/rim/trim mesh-name mapping are the only
places that need updating.
